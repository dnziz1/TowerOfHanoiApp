# TowerOfHanoiApp

A C# implementation of the Tower of Hanoi puzzle with visual console animation, following Marcin Jamro's design.

## Features
- Recursive algorithm implementation
- Real-time visualization in the console
- Configurable number of disks
- Move counter

## How to Run
1. Open in Visual Studio or any C# IDE.
2. Build the project and run it.
3. Watch the Tower of Hanoi puzzle being solved step-by-step in the console.

## Algorithm
Uses the classic recursive approach with three stacks representing the towers.
